# 候选质量与安全规则

## 候选评估

对每篇论文分别记录，避免只给一个模糊总分：

| 维度 | 判断问题 |
|---|---|
| 主题 | 是否直接回答研究主题，而非只出现关键词 |
| 方法 | 研究方法、模型或管理框架是否真实匹配 |
| 场景 | 行业、组织、项目类型和研究对象是否可迁移 |
| 来源 | 是否满足用户指定的来源层次或文献类型 |
| 时效 | 是否处于年份窗口；经典文献是否有保留理由 |
| 证据 | 判断来自题名、摘要、详情页还是全文 |
| 元数据 | 作者、来源、年份、卷期、页码、DOI 是否完整 |
| 来源轨迹 | 查询式、数据库、原始记录和合并来源是否可追溯 |

推荐分类：

- `主参考`：主题、方法和场景高度匹配，且有详情页或全文证据。
- `辅助参考`：至少两个核心维度匹配，可支撑方法或案例。
- `背景材料`：解释行业、政策、技术或概念背景。
- `待核验`：元数据匹配但未获得摘要或全文证据。
- `剔除`：关键方法或场景不匹配，或元数据无法验证。

## 检索停止条件

遇到以下任一情况暂停知网访问：

- 可见验证码或人机验证。
- 登录状态失效。
- 机构或个人账号没有访问/下载权限。
- 同类请求连续失败 3 次。
- 响应为空、格式异常或明显是登录/错误页面。
- 用户设定的严格条件没有足够候选。

暂停后保留已取得的合法元数据，并说明未完成部分。不要换 IP、修改代理、提取 Cookie、伪造请求头或使用其他方式规避访问控制。

## 下载检查

1. 在详情页确认题名与候选记录一致。
2. 只使用页面提供的合法 PDF/CAJ 下载入口。
3. PDF 首字节必须为 `%PDF`。
4. 文件大小异常、HTML 登录页或 JSON 错误响应均判定为失败。
5. 下载完成不等于适用；必须进行全文核验后才能标为主参考。

## 引用检查

- 期刊论文 `[J]`：核对刊名、年份、卷、期、页码。
- 学位论文 `[D]`：核对授予单位和年份。
- 会议论文 `[C]`：核对会议或论文集信息。
- 图书 `[M]`：核对出版地、出版社和年份。
- 网络首发：保留在线发表信息，但不能冒充正式卷期页码。
- DOI：只使用可解析且元数据一致的 DOI。
- 缺失字段：标记待核验，不推断、不补造。
- 英文 DOI：优先通过 `paper-search-pro --verify-refs`、Crossref 或期刊官网核验；仅有题名相似不得标为已核验。
- 跨语种记录：只有 DOI 一致时自动合并；译名相似只能标记为人工复核候选。

## 报告证据标签

建议在结论后标注：

- `[检索页]`：仅来自搜索结果元数据。
- `[详情页]`：已核对摘要、关键词或出版信息。
- `[全文]`：已阅读并核对方法或结论。
- `[外部核验]`：已通过 DOI、期刊官网或 Zotero 数据核对。

## 英文 API 安全

- 遵守 OpenAlex、Semantic Scholar、Crossref、PubMed 和 arXiv 的配额与速率限制。
- 不抓取 Google Scholar 结果页，不轮换代理或账号规避 429。
- 遇到 `E_RATE_LIMITED`、持续 429 或配额不足时保存日志并停止该来源。
- `paper-search-pro` 的 `heuristic_v1` 不等于人工相关性评分；最终等级必须由题名、摘要或全文证据支持。
